# Annotation guideline (Bengali book review sentiment)
Work alone, do not discuss, do not look at ratings. Read each review and fill `label_P_N_U`:
- P = the reviewer is overall positive about the book (even with small complaints)
- N = the reviewer is overall negative about the book (also complaints about translation/print/delivery that make them dislike the book)
- U = no clear opinion (plot summary, joke, religious text, question, mixed with no overall lean)
Judge the text only. Return the CSV. ~200 items, about 1 hour per annotator.
